# Archived legacy client

This directory preserves the pre-TypeScript Interminal client for regression and migration reference.

It is not the production application entry point. The active UI lives under `src/`, is built by Vite, and is the implementation described by the root README and current security documentation.

Do not use files in this directory as evidence of current product behavior, deployed contract provenance, live market-data behavior, or mainnet execution guarantees.
